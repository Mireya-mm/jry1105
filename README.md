## 一、项目背景（模板）

`fsg-contract` 是一项围绕「合同业务」的发现（Discovery）练习。目标是在 *机会阶段* 通过业务挖掘、 stakeholder 访谈、现场调研与现状流程梳理，识别合同业务中的痛点、机会与可落地的改进方向。

> 说明：本仓库为训练/模板性质，正文中的具体数据、人员、流程均为「示例/占位」，请按真实项目情况替换。

## 二、FDE 方法论（模板）

FDE 取义于 **Find（发现）— Diagnose（诊断）— Enable（赋能）** 三段式：

1. **Find 发现**：通过业务挖掘与访谈，把模糊的「业务感觉」转化为可验证的问题清单。
2. **Diagnose 诊断**：结合现场调研与原有资料，定位根因、量化影响。
3. **Enable 赋能**：基于现状流程图，设计改进方案并推动落地。
