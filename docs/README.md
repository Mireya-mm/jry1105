## 使用说明

1. 每个子文档均以「模板/示例」形式给出结构，请按真实调研结果填充。
2. 访谈记录同时提供 `md`（可读）、`json`（结构化）、`csv`（表格）三种格式，便于导入分析工具。
3. 现状流程图使用 Mermaid 语法，可在 GitHub 或支持 Mermaid 的编辑器中直接渲染。
4. 后续阶段（如方案设计、落地）可沿用本目录结构继续补充。
